# **App Name**: Jornada Financeira

## Core Features:

- Perfil Gamificado: Apresentar visualmente o perfil de gamificação do usuário, incluindo nível, XP e atributos de progresso nas áreas de Alimentação, Lazer, etc.
- Visualização de Finanças: Interface de usuário para visualizar contas bancárias, cartões de crédito e transações financeiras.
- Gerenciamento de Dados Financeiros: Interface para criação, edição e exclusão de contas, cartões e transações.
- Relatórios Financeiros: Sistema de relatórios que utiliza dados de transações para gerar gráficos e resumos visuais das finanças do usuário.
- Autenticação Segura: Sistema de autenticação com registro e login, garantindo a segurança dos dados do usuário.
- Gamificação do Progresso Financeiro: Implementação de lógica para calcular e recompensar o usuário com XP e conquistas com base em seus hábitos financeiros.
- Descoberta de Hábitos: Use a generative AI tool to help the user discover which spending habits are costing them the most "points."

## Style Guidelines:

- Cor primária: Verde suave (#A5D6A7) para simbolizar crescimento financeiro e tranquilidade.
- Cor de fundo: Branco acinzentado (#F5F5F5) para um visual limpo e moderno.
- Cor de destaque: Azul vibrante (#64B5F6) para botões de ação e elementos interativos.
- Fonte para corpo e títulos: 'Inter', uma sans-serif com uma aparência moderna e neutra.
- Ícones minimalistas e intuitivos para representar diferentes categorias de transações e elementos da interface.
- Design limpo e organizado com foco na usabilidade, facilitando a navegação e a compreensão das informações financeiras.
- Animações sutis e responsivas para melhorar a experiência do usuário, como ao adicionar uma nova transação ou alcançar uma conquista.
