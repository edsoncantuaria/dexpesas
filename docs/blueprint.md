# **App Name**: Dexpesas

## Core Features:

- Expense Tracking: Log and categorize expenses manually.
- Income Tracking: Log and categorize income manually.
- Basic Reporting: Generate simple reports based on income and expenses.
- AI-Powered Budget Tool: Based on the current level of expenses, assist the user to find possible changes to the expenses
- Simple Visualizations: Visualize income and expense data using charts and graphs.

## Style Guidelines:

- Background color: Light gray (#F4F4F4) for a clean, neutral backdrop.
- Primary color: Forest green (#228B22) for a natural association with growth and finances.
- Accent color: Warm yellow (#FFD700) to highlight important information and call-to-action elements.
- Font pairing: 'Inter' (sans-serif) for both headings and body text to maintain a modern and easily readable interface.
- Use flat, line-art icons in a consistent style to represent expense categories and actions.
- Emphasize simplicity and easy navigation.
- Incorporate subtle animations, such as a smooth transition between screens or a loading animation when data is being processed.
